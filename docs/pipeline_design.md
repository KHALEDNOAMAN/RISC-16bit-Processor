# Pipelined RISC Processor Design

## 5-Stage Pipeline
1. **IF** - Instruction Fetch
2. **ID** - Instruction Decode
3. **EX** - Execute
4. **MEM** - Memory Access
5. **WB** - Write Back

## Hazards
- **Data Hazard**: Forwarding/stalling
- **Control Hazard**: Branch prediction
- **Structural Hazard**: Resource conflicts
